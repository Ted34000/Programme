# Carnet de projets

Page web pour noter ses idées vite et les ranger.

- **Notes** : mur d'idées. On tape, Entrée, c'est enregistré. Couleur, projet, épingle, transformation en tâche.
- **Projets** : projets et sous-projets. Chacun a sa couleur, sa police, sa taille d'écriture et son logo (bouton « Personnaliser »). Les sous-projets listent les outils à utiliser (Claude Code, Excel, CapCut…).
- **To do** : tâches avec projet, échéance et priorité, regroupées par En retard / Aujourd'hui / Cette semaine / Plus tard.

Publiée en artifact claude.ai : les données sont dans la base de l'artifact, donc synchronisées entre le PC et le téléphone. Ouvert hors claude.ai, le fichier HTML enregistre dans le navigateur (localStorage).
